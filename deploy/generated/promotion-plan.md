# Promotion plan

Generated by `npm run deploy:render`. Do not edit; change `server/src/platform/topology.ts`.

Two image digests are built once and promoted: the lean service image and
the CPU-only Maia serving target. Every command below names a digest, so
what is smoke-tested is byte-identical to what serves traffic.

## 1. Build the two digests

```bash
gcloud builds submit --project tempo-chess-neri --region europe-west1 \
  --tag europe-west1-docker.pkg.dev/tempo-chess-neri/cloud-run-source-deploy/forma:$(git rev-parse --short HEAD)

gcloud builds submit --project tempo-chess-neri --region europe-west1 \
  --config cloudbuild.maia3.yaml \
  --substitutions=_IMAGE=europe-west1-docker.pkg.dev/tempo-chess-neri/cloud-run-source-deploy/forma-maia:$(git rev-parse --short HEAD)
```

Record the resulting digests as `BASE_DIGEST` and `MAIA_DIGEST`.
Nothing below builds again.

## 2. Stage the digest with no traffic

Decision D2: staging is a tagged revision of the same service, not a second
project. `--no-traffic --tag=next` gives a reachable URL that serves nobody.

  --ingress all --allow-unauthenticated \
  --max-instances 6 --concurrency 40 \
  --cpu 1 --memory 1Gi --timeout 30 \

## 3. Smoke the staged revision

```bash
curl -fsS "$(gcloud run services describe forma-api --project tempo-chess-neri
  --region europe-west1 --format='value(status.traffic.filter(tag:next).url)')/health"
```

Private services are not curled from a laptop by design; their smoke is the
scheduler's next authenticated invocation and the queue drain below.

## 4. Promote

```bash
gcloud run services update-traffic forma-api --project tempo-chess-neri --region europe-west1 --to-tags next=100
gcloud run services update-traffic forma-ops --project tempo-chess-neri --region europe-west1 --to-tags next=100
gcloud run services update-traffic forma-ingestion --project tempo-chess-neri --region europe-west1 --to-tags next=100
gcloud run services update-traffic forma-stockfish --project tempo-chess-neri --region europe-west1 --to-tags next=100
gcloud run services update-traffic forma-maia --project tempo-chess-neri --region europe-west1 --to-tags next=100
gcloud run services update-traffic forma-analysis --project tempo-chess-neri --region europe-west1 --to-tags next=100
```

## 5. Rollback

The previous revision is still there and still healthy; rollback is traffic,
not a rebuild.

```bash
gcloud run services update-traffic <service> --project tempo-chess-neri --region europe-west1 --to-revisions <previous>=100
```
